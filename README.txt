Doqurix - Installation

Thank you for installing Doqurix!

This application uses advanced AI technology to:
- Answer questions from your PDF documents
- Generate summaries of document content
- Provide context-aware responses with source citations
- 🇩🇪 NEW: Built-in German Tax Agent with comprehensive tax knowledge

System Requirements:
- Windows 10 or later (64-bit)
- Minimum 8GB RAM
- 5GB free disk space for AI models

First Run:
The application will download AI models (~1GB) on first launch.
This is a one-time download and will be cached for future use.

Features:
- Fast AI-powered Q&A
- Quick and Detailed search modes
- Context highlighting
- Source citations
- Professional responses
- Multi-agent system (Document Analysis, Insights, German Tax Expert)
- Web interface for modern chat experience

Agent Modes:
1. None - Standard document Q&A with your uploaded PDFs
2. Insights - Automatic document analysis and key findings
3. Tax Germany - Expert German tax knowledge (no PDF upload needed)
   • Income Tax (Einkommensteuer)
   • VAT (Umsatzsteuer)
   • Corporate & Trade Tax
   • Church Tax, Capital Gains, Real Estate Transfer Tax
   • And more...
